# 包内容与依赖边界

| 项目 | 源码包 `source/` | Windows 客户包 `toolkit/` |
|---|---|---|
| 自有源码 MIT、原版权与第三方许可 | 保留 | 保留 |
| 48 Skill、当前 CLI/注册/核心源代码 | 保留完整静态源码 | 保留运行需要的原字节 |
| 维护回归、参考源、构建/核验工具 | 保留源码与合成生成器；无测试结果 | 排除测试专用工具 |
| 历史 tests 路径内的 `nonlinear_prediction/tests/render.R` | 保留 | 保留：实际 run_module.py 调用且原锁绑定的运行投影器 |
| 当前客户 Markdown 教程与公开 PBC 生成器 | 保留 | 保留；`examples/make_public_pbc.R` 不输出标识 |
| 历史 final8/PDF/检查回执/个人绝对路径 | 不放入源码 ZIP；原仓库与旧证据保留 | 排除 |
| Python 3.14.5、R 4.6.1 及推荐库 | 不包含 | 外部官方安装 |
| 26 个 Python 依赖（含 SHAP vendor 三项） | 固定 URL/SHA/许可与锁 | 官方下载或独立离线 wheel 缓存安装；不捆已安装环境 |
| 14 个 R 依赖 | 原 CRAN 二进制 ZIP 与匹配源码 tar.gz | 同样保留原归档和原声明 |
| Python 第三方许可副本 | 原 wheel 内文本逐字节复制并记录 SHA | 同样保留；不替换原 wheel / dist-info 声明 |
| `.runtime`、缓存、日志、冻结模型、研究 CSV/PBC 夹具、数据库、历史包、Git 历史 | 排除 | 排除 |

源码包保留维护代码，不等于把维护工具暴露为客户功能。核心部分含被原运行时锁绑定的历史接口/未登记资产；保留其字节以满足原源码合同，不恢复选题/CRF/写作投稿产品路线。具体前台仍限现有 33 后端、8 别名、11 视图、5 检验、4 规划。

第三方 R 原归档可能自带上游教学示例与数据，按原包保留；这里的排除指额外研究输入、客户数据、PBC 投影及数据库，不声称原依赖归档没有上游示例数据。

客户包从原静态 toolkit 选择成员，再在内存中生成只覆盖实际 Skill 文件的 `toolkit-manifest.json`，不改仓库主清单。48 Skill 发现目录保留；未安装依赖、旧 PDF 和旧测试摘要不作当前包能力或下载承诺。完整逐文件清单由构建计划生成，不靠此表猜测成员。

许可权属按 `LICENSE-SCOPE.md` 分开：自有部分 MIT；第三方依其 GPL/LGPL/Apache/BSD/MPL/PSF/MIT 等原条款。GPL R 组件的匹配源码随二进制归档一并保留；Python 复杂捆绑许可以实际 METADATA / 原许可文本为准，不将分类器简化为整个 wheel 的唯一许可。公开 PBC 不含数据行，不对独立数据许可作额外保证。
