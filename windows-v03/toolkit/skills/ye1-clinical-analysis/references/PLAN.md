# 从问题到分析

先核安装与方法依赖，再理解研究问题。询问会改变统计合同的缺失信息：独立单位/配对/重复、变量含义与单位、结局编码、分组参考、时间起点与可知性、缺失、权重和预设模型。一次澄清关键问题；不让用户挑schema或填JSON。

按能力矩阵选最少必要的登记方法；组合需各自研究目的，不能强制旧全流程。先声明估计量、入排、样本/切分和时间规则，再读取原始数据。按LOCAL-DRAFTS.md生成元数据并由本地准备器生成私有任务。真实数据需要本地人类确认。

运行后核原结果状态、样本流/分母、表图和解释尺度。计算完成但展示失败单列，不将exit0当最终验收。某模型被阻止保留理由，不删行、抽样、换模型或为显著性改方案。模型与视图保持来源/内容hash/版本绑定，冻结应用不得重训。

返回允许披露的结果、适用限制、实际完成/失败/未测项与本地证据路径。不得将合成测试、共享owner对照或数量盘点称科学认证、独立优化器验证或真实客户验证。
