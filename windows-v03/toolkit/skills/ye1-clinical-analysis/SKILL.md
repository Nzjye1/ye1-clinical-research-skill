# 临床分析总入口

本产品为0.3.2-windows-local-noninteractive1本地候选，逐项合成工程证据见[能力矩阵](references/CAPABILITIES.md)。33个后端方法ID、8个别名、11个已有结果视图及1个旧受限入口分别标记，不能按目录或Skill数宣传算法数，也不能把旧四方法验收扩大为本版全部通过。

用户可用普通中文提出问题，也可点名同级单项Skill。先理解研究单位、变量/单位/编码、结局/时间定义、缺失、抽样/重复/竞争事件和所需产物，集中澄清决定方法的信息。按问题选择原已实现的owner和已登记操作；用户不需要选择JSON/schema或修代码。只组合确有必要且已确认的步骤，每项输出新目录，冻结模型在评价/推理时不重拟合。

首次读取数据前读[数据条件](references/PRIVACY.md)，先安装/自检；基线等基础任务不能被无关高级依赖阻塞。患者行/标识/私有模型/日志不进入聊天或外部模型；真实输入使用调用方指定的本地文件和任务参数，经捕获调用准入，不伪造身份、host证明或把real改synthetic。普通Codex不提供全局隔离；严格不可访问原件要求应暂停数据步骤。

用scripts/toolkit.py list发现中文名/稳定ID/操作。只加载选定方法describe/schema及必要说明，Agent准备本地任务，不盲套示例字段/样本/事件码。单项Skill共享本目录数值底座，不能复制或重写算法。`schema`可在无运行依赖时查看，不能把schema成功当作分析通过。执行前doctor对应方法及依赖组，额外软件安装须说明来源/本地位置并按当前规则取得许可。

按原合同的适用边界执行，核真实CSV/PNG、分母、缺失、版本、诊断和解释；不只看返回0，不为显著性切模型/删异常值，不静默去重或截样。结果和科学复核pending分别报告；已有视图只提取，不拟合。真实结果先本地查看，对话只回固定状态/路径，内容回传仍需原审阅授权。

正式能力矩阵已逐项列出可调用状态、条件、版本/合成证据及未验/未完成项。旧兼容统计检验/样本量、AJ/原因别Cox及旧描述轨迹等资产另列迁入决定，不无声遗漏；定义不明的复合指标和新研究方法不凭空实现。数据库获取、写作/投稿和强制全流程不恢复。Mac/WorkBuddy、真实患者/宿主隐私、物理新电脑或完整新GUI会话未测则明确未测。

首次执行请读[本地草稿与调用接口](references/LOCAL-DRAFTS.md)，按[安装教程](INSTALL.md)先自检；[原35项追踪](references/ORIGINAL-35.md)区分限定实现、部分和待定义。

开发分支另有[固定公开PBC案例验收](references/PUBLIC-FIXTURES.md)：仅精确来源/版本/许可/hash的两列夹具可由 `public-fixture` 自动完成软件数值和产物检查。它独立调用原KM owner，不改变普通客户分析流程，不接受任意公开CSV，不等于临床科学复核、真实客户全链或发布完成。

本地R探针若被宿主执行边界拦截，先按INSTALL.md诊断并遵守宿主权限流程；只在获得相应本地执行许可后重试，不修改系统安全设置或伪造通过。
