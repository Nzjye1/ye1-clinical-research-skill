# Explicit scope limits and pending integration

- Observed numeric training feature ranges are unrecoverable from a model-only v10 wrapper. Prespecified display domains are supported and are never labeled as observed training support.
- The module supports the existing single-event, independent-subject, right-censored v10 model only. Evaluation has no conditional censoring model, uncertainty intervals, formal proportional-hazards tests or causal interpretation.
- Explain/nomogram requests outside frozen display domains are refused as a whole. Standalone unrestricted attribution is not exposed in this bounded candidate.
- The sidecar supports the analytic frozen training-centering mean reference only. Alternative backgrounds, conditional SHAP and probability SHAP are refused rather than approximated.
- The two table adapters are synthetic, explicit normalization demonstrations. They do not read or certify real MIMIC/eICU databases or establish cohort independence.
- Public task normalization, trusted common bindings, registry/dispatcher integration and the final integrated regression gate are the integration owner's work. Module-local receipts are not evidence that those gates passed.
- Initial transport failures are preserved in acceptance evidence. The host's redirected default temporary directory was unwritable; current transient files are confined to the module. The host's R file-access probe was unreliable; source hashing reuses the existing core bounded binary-read helper.
- No package installation, real database scan, network upload, model migration or historical evidence cleanup is part of this module.
